# Bistro Rush privacy policy

Public privacy-policy website for Bistro Rush, built as a self-contained static HTML page.

- **Developer:** Agara Studio
- **Application identifier:** `com.agara.bistrorush`

**Website:** https://kresnaputra.github.io/bistro-rush-privacy/

## Preview locally

```sh
python3 -m http.server 8080
```

Open http://localhost:8080/. The page follows your device's light/dark appearance setting.

## Publishing

GitHub Pages serves the `main` branch from the repository root. No build step, JavaScript,
analytics, third-party fonts, or tracking scripts are required.

The game source and native build artifacts belong to a separate private repository.

## Maintenance

The policy describes the current version: local progress, no accounts, no analytics, and no
advertising SDKs. Update the policy and its date if the App's data practices change.
